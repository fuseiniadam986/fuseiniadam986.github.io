迁移准备 · 更新于 2026-09-20

网站迁移到香港服务器前，要准备哪些数据和回退方案

迁移不是把文件复制过去就结束。真正稳妥的迁移，需要提前准备数据备份、运行环境、DNS 切换、证书、测试和回退方案。

迁移前检查清单

项目要准备什么
网站文件代码、图片、上传目录、配置文件
数据库完整备份、导出时间、字符集、恢复测试
运行环境PHP、Node、Python、Nginx、数据库版本
域名 DNS当前解析记录、TTL、切换时间
HTTPS 证书证书申请、续期方式、强制 HTTPS 设置
回退方案旧服务器保留时间、回切步骤、负责人

上线当天不要做太多未知变更

迁移期间同时换程序、换数据库版本、换缓存策略，会让问题排查变复杂。建议先完成等价迁移，再逐步优化配置。

什么时候需要人工协助

  • 网站有数据库或后台系统。
  • 业务不能长时间中断。
  • 不确定服务器环境如何复刻。
  • 域名、证书、邮件、CDN 同时需要调整。
  • 需要在低峰时间完成切换并可回退。
